Estructura del Código

Cómo se construyó esta app paso a paso

1. Estructura (HTML5)

La aplicación está organizada en 3 secciones principales dentro de un contenedor contenedor flex: #menuSection, #quizSection, y #resultsSection. Usamos clases de visibilidad (hidden) para alternar entre pantallas sin recargar la página (Single Page App).

2. Estilos y Efectos (Tailwind CSS)

Se utiliza Tailwind CSS para un diseño ágil y moderno. Puntos destacados:

  • Glassmorphism: Fondo translúcido con backdrop-blur-md y bordes sutiles.
  • Gradientes Neón: Colores vibrantes mezclando violeta, cian y rosa.
  • Keyframes: Animaciones personalizadas como fadeIn y popIn.
3. Lógica de Estado (JavaScript ES6)

El script gestiona la reactividad y los datos del juego:

  • Estado global: Mantiene el índice actual, tipo de quiz, puntuación y acumulador de perfiles.
  • Temporizador: setInterval de 15s que descuenta el tiempo en tiempo real para el modo Trivia.
  • Renderizado Dinámico: Manipulación directa del DOM para inyectar preguntas y botones.
  • Feedback y Confeti: Lógica condicional que dispara la librería external canvas-confetti al ganar.
